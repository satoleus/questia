# 旧・同梱ガチャ画像フォルダ

現在のQuestiaはこのフォルダを自動では読み込みません。キャラクター追加には、
次のどちらかを使用してください。

- ガチャ画面の「キャラクターを登録」
- 設定画面の「召喚ライブラリ」から`.questiapack`をインストール

推奨形式：

- WebP
- 縦長（3:4〜4:5）
- 長辺900〜1200px
- 1枚500KB以下
- 半角英数字のファイル名（例：`mio.webp`）

複数キャラクターを配布する場合は、`docs/questia-character-pack-spec.md`に
従ってパックを作成してください。画像をこのフォルダへ置くだけでは登録されません。
