# questia
ストップウォッチ、ポモドーロタイマー、カレンダー、ガチャ機能を実装した作業配信風アプリ（テスト）

## デフォルトのガチャキャラクターを追加する

`examples/images` の次のフォルダへ画像を入れます。画像のファイル名（拡張子を除く）が、そのままキャラクター名になります。

- `レア（R）`
- `超レア（SR）`
- `超激レア（SSR）`

画像を追加・差し替えた後、プロジェクト直下で次を実行します。

```bash
./scripts/sync-default-characters.sh
```

ガチャ用の画像とコレクション用サムネイルがWebPへ自動変換され、`default-characters.js` の登録情報も更新されます。同じレアリティ・同じキャラクター名で画像を差し替えた場合はIDが維持されます。
